# Carta Evento TCG

Carta de comida para celular del stand del evento TCG. Pensada para abrirse desde un código QR.

## Contenido

- `index.html`: la carta (HTML estático, sin dependencias externas).
- `css/menu.css`: estilos y fuentes (Bricolage Grotesque y Archivo, incluidas en `fonts/`).
- `js/menu.js`: flechas de la barra de categorías.
- `img/`: fotos de los productos.

## Publicar con GitHub Pages

1. En el repositorio, ir a **Settings → Pages**.
2. En **Source**, elegir **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. Guardar. La carta queda en `https://dmunozclsnce.github.io/carta_evento_tcg/`. Ese es el enlace para el código QR.
